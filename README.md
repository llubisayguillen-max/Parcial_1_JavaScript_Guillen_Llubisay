# Tareas Estudiantiles

Aplicación web simple para la gestión de tareas que permite la interacción con el usuario, se practica la manipulación de la interfaz (DOM) y la persistencia de datos,
desarrollada con **JavaScript**, **HTML** y **Bootstrap**. 

Permite agregar tareas, cambiar su estado y visualizarlas en una tabla organizada.

---

## Funcionalidades

- Agregar nuevas tareas
- Cambiar estado de tareas:
  - Iniciada
  - En progreso
  - Finalizada
- Buscar tareas
- Eliminar tareas
- Persistencia con LocalStorage

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
